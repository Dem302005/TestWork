# Technical Game Designer Test - Dem302005

## 🚀 Project Overview

This project was developed for the **Technical Game Designer** test challenge at Gameloft.

The scene, **"Forgotten Ruins: Path to the Portal,"** represents the ruins of a long-lost civilization. The main heroine (the controllable player character), having crash-landed, finds herself on this planet. Her goal is to explore the ruins in search of materials to repair her ship or to activate a portal that can serve as an exit.

The project demonstrates the setup of core game systems—camera, physics, and animations—and the implementation of **complex trigger-based interactions** necessary to progress through the level.

## ⚙️ Technical Requirements

* **Engine:** Unity 2020.3.0f1 (LTS)
* **Platform:** PC

## 🛠️ Setup Instructions

To properly open and test the scene, please follow these steps:

1.  **Clone/Download:** Download (clone) this repository to your computer.
2.  **Open Project:** Open the project folder using Unity Hub (ensure Unity version **2020.3.0f1** is installed).
3.  **Starting Scene:** In the **Project** window, navigate to the folder: `TestGame/Assets/Scenes` and open the **Start** scene.
4.  **Launch:** Press the **Play** button in the Unity editor.
5.  **Level Transition:** Click the **Start** button in the main menu to load the main gameplay scene, **Level1Test**.

## 💡 Step-by-Step Level Progression

To successfully complete the gameplay scene, you must perform the following actions in order:

1.  **Crossing:** Cross the river to reach the second bank.
2.  **Gate Activation 1:** Step on the two glowing **pressure plates** to open the first set of gates.
3.  **Crystal Activation 1:** Enter the structure on the **left** and activate the first **key crystal** there.
4.  **Crystal Activation 2:** Enter the structure **opposite** (across the path) and activate the second **key crystal** there.
5.  **Final Encounter:** Activating both crystals will open the **main gates** leading to the portal. The portal is guarded by **two sentinels**. You must defeat them to remove the portal's barrier.
6.  **Completion:** Enter the portal to complete the game and return to the **Start** scene.
